Database Connection
Setting up the online database (one time)
  1. Create a free account at supabase.com and a new project (choose the region closest to Ghana, e.g. Europe West).
  2. Open SQL Editor, paste the contents of supabase_setup.sql, and click Run.
  3. In Authentication → Sign In / Providers → Email, turn Confirm email off (or staff must click the link in their email first).
  4. Click Connect at the top of the Supabase project (or Project Settings → API) and copy the Project URL and the anon public key into this app (sign-in screen → ⚙ Database connection), or into the two lines at the top of this file's script so every copy connects automatically.
  5. The Proprietor creates the first account: that account automatically becomes the Proprietor. Other staff then create accounts and the Proprietor approves them.
  6. Put this file online (e.g. Netlify Drop or GitHub Pages) or send the file to staff phones. Wherever it is opened, everyone works on the same records.
